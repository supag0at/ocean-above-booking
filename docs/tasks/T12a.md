# T12a 前端联调

公共规则见 [W4-common.md](W4-common.md)。只写前端（R-U1）。

- **目标**：`apps/web` 在 `VITE_MOCK=0` 时走真实 gateway，不再走 MSW。默认（不设这个变量）仍然走 mock，现有单测保持绿色。
- **只能改**：`apps/web/**`、`docs/tasks/T12a.md`。
- **做法**：
  1. Vite 把 `/api` 代理到 `http://127.0.0.1:8080`（gateway 公共端口）。浏览器继续用相对路径和 `credentials: 'same-origin'`，这样 cookie 和 CSRF 不用改成跨域。
  2. `VITE_MOCK=0` 时不启动 MSW（`main.tsx` 里已有这个判断，确认它覆盖登录、会话、SSE、报价卡、机票、记忆、历史）。
  3. SSE 断线重连继续带 `Last-Event-ID`。代理要放行流式响应，不要把 SSE 缓冲完再转发。
  4. 本地联调时 gateway 的 `PUBLIC_ORIGIN` 必须是 `http://127.0.0.1:5173`（CSRF 对 Origin 做全等比较）。这个环境变量由 T12b 的启动脚本设置，你只在任务文档里写明前端怎么配合，不要改 `services/`。
- **验收**：
  1. `pnpm --filter @fb/web test` 在默认 mock 下通过。
  2. `pnpm check` 9 步通过。
  3. 用真实 gateway 走通一次：登录、建会话、发一条消息、看到 SSE 事件。gateway 用本 worktree 里已有的代码起（只运行，不修改）。没有 Docker 或后端起不来时，把卡点写进汇报，不要改后端。
- **不做什么**：不改视觉、不加页面、不装新依赖。
