# A-01 前后端架构设计

- 目标：产出前后端架构设计和结构层契约草案（接口、数据归属、运行拓扑三类为主，其余三类覆盖前后端部分），作为 T00–T15 的开发约束。
- 范围：
  - 模块和目录切分：monorepo，对应 D-15 下的各个包和服务；
  - 依赖规则（谁能 import 谁）；
  - 进程和容器拓扑、compose 网络分段、每个容器的凭证和环境变量（H-07）；
  - REST / SSE 接口（登录、会话、事件流、发消息、确认下单、我的机票、历史对话、画像查看 / 删除）；
  - 事件信封和持久化规则、用户侧 / 系统侧事件类型；
  - session 内部 API 的 HTTP 形状；
  - Postgres 表结构、数据库角色和授权（events 只追加、tickets 只有 booking 能写、报价兑换只能插入一次）；
  - 确认下单链路（按钮 → gateway → booking），包括 CSRF、幂等和错误码；
  - 前端结构：路由、组件、状态管理、SSE 断线续传、报价卡数据从 API 取、i18n、XSS 防护（LLM 文本不渲染成原始 HTML）；
  - 可观测性：traceId 透传、日志格式、预留 OTel 接口；
  - Redis 的用途和 key 规划，包括 BullMQ；
  - 部署：虚拟机、Caddy、还没有域名时怎么访问；
  - 以上每一块的失败语义（重试、超时、部分失败）。
- 不做：agent 内部设计（归 A-02，见 [W1-seams.md](W1-seams.md)）；写代码；定契约终稿。

- 只能改：`docs/design/A-01-frontend-backend.md`（如果需要图，可以加 `docs/design/A-01-*.md`）

  2. 六类契约里前后端相关的部分都写到了可以直接实现的粒度（字段、类型、错误码、授权语句）；
