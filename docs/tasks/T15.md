## 要覆盖的路径

用浏览器走完，不只看接口：

1. 只填用户名登录，看到空的会话列表（不是 MSW 的种子数据）。
2. 发送「从上海飞圣保罗」。过程区可以短暂出现思考文字。报价卡上的城市名和价格来自 `GET /quotes/:id`，与卡片上显示的字符串一致。
3. 在输入框里发送「确认」不出票。点击报价卡上的确认才出票。同一张卡再点一次，仍然只有一张票（`alreadyBooked`）。
4. 刷新后续上 SSE（`Last-Event-ID`），已经落库的对话还在。
5. 把 gateway 容器停掉再启动，静态页仍由 Caddy 提供；gateway 恢复后可以重新登录。
6. 用户 A 看不到用户 B 的会话和机票。

需要真实模型的步骤控制在 6 次 DeepSeek 调用以内。崩溃和隔离用 Docker 操作，不再另起一套栈。失败时把容器日志写进汇报，不要放宽断言。
