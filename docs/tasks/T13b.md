# T13b 跑评测

- 档位：T3。等 T15 交回后再派。用户要求评测放在部署和端到端之后。
- 只能改：`eval/runner/**`、`eval/reports/**`、`docs/tasks/T13b.md`。
- 不改 `eval/cases/**`、`eval/oracle/**`、服务代码和 compose。

## 怎么跑

1. 先跑 `eval/cases` 里的确定性用例（不调用模型）。数字和 `eval/oracle` 不一致时两边都记下来，不要改用例，也不要默认哪一边对。
2. 再跑 agent 用例。断言只看事件日志，不看模型原文是否漂亮。每条用例最多跑到文件里写的次数，但**整次任务的真实 DeepSeek 调用不得超过剩余额度**。额度在派发时由父会话写进汇报模板（此刻是 50 次里已用 23 次）。快到上限就停，把没跑的 id 列进报告。
3. 报告写到 `eval/reports/`，按 `eval/cases/README.md` 的门槛算通过率。历史类里标了 `runner: e2e` 的条目引用 T15 的结果，不要重跑。

## 验收

报告文件在仓库里，命令可以复跑确定性的那一部分。`pnpm check` 不因本任务变红。
