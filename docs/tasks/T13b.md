## 怎么跑

1. 先跑 `eval/cases` 里的确定性用例（不调用模型）。数字和 `eval/oracle` 不一致时两边都记下来，不要改用例，也不要默认哪一边对。
2. 再跑 agent 用例。断言只看事件日志，不看模型原文是否漂亮。文件里写的是每条 5 次，这次只跑 **1 次**。真实 DeepSeek 调用上限 **20 次**（端到端已经用过额度，不再按 5 次重复）。快到上限就停，把没跑的 id 列进报告。优先跑门槛是 100% 的分类（confirm_flow、numbers、redteam、failure），然后是 route 里「从上海飞圣保罗」那条。
3. 报告写到 `eval/reports/`，按 `eval/cases/README.md` 的门槛算通过率。分母只算实际跑过的次数，没跑的单独列出，不要算成失败。历史类里标了 `runner: e2e` 的两条引用 T15（`5459a7f`，6 条浏览器旅程通过），不要重跑。
