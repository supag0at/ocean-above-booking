## agent 用例

断言只看 gateway 内部事件日志（经 harness 容器里的 node 读取；服务令牌不打印）。登录、发消息、点击确认走 `http://127.0.0.1/api/v1`。没有直接调用 DeepSeek。每条只跑 1 次。

模型调用按事件日志计算：每个 run 取 `agent.run_completed.payload.usage.requests` 与「非模板 assistant 消息数」的较大值。生产 harness 没有把 `request_start` 打进日志，失败且未落成消息的请求不会出现在这个数里。本次没有跑故障注入，正常回合的完成次数就是这个数。
